# Rivo

Marka × içerik üreticisi işbirliği platformu (demo).

## Çalıştırma

```bash
cd web
npm install
npm run dev
```

Aç: [http://localhost:3000](http://localhost:3000)

## Demo hesaplar

| Rol | E-posta |
|-----|---------|
| Marka | `brand@rivo.demo` |
| Üretici | `influencer@rivo.demo` |
| Ajans | `agency@rivo.demo` |

## Admin

Giriş: `/login` → Yönetici girişi

- Kullanıcı: `rivoadmin`
- Şifre: `Rivo2026!`

## Özellikler

- Marka / üretici / ajans rolleri + onboarding
- Keşfet, teklif müzakeresi, escrow işbirliği akışı
- Thread sohbet (okunmamış sayaç, arama, filtre)
- Admin paneli + audit log

## Stack

Next.js · React · Tailwind · Framer Motion · JSON dosya DB
