# Rivo

Marka × üretici işbirliği platformu. Kısa marka adı, canlı tanıtım, Apple/Google (simüle) giriş ve rol bazlı onboarding.

## Çalıştır

```bash
export PATH="$HOME/.local/node/bin:$PATH"
cd web
npm install
npm run dev
```

→ http://localhost:3000

## Marka

- **Ad:** Rivo  
- **Önerilen domain:** `rivo.app` / `rivo.so` / `getrivo.com` (kayıt öncesi whois kontrol edin)  
- **Logo:** `public/rivo-mark.jpg`
